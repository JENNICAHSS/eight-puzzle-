What is the 8-Puzzle Problem?

The 8-Puzzle is a sliding-tile puzzle played on a 3×3 board. Eight tiles numbered 1–8 share the board with one empty square (the blank). A move slides a tile that is next to the blank into it — equivalently, the blank moves Up, Down, Left or Right. The task is to transform a given initial state into a goal state using as few moves as possible.

As a state-space search problem

  • State: an arrangement of the nine squares (9!/2 = 181,440 reachable states).
  • Initial / Goal state: supplied by the user (or generated randomly).
  • Actions: move the blank Up, Down, Left or Right (2–4 legal actions).
  • Transition model: swap the blank with the neighbouring tile.
  • Path cost: 1 per move, so path cost = number of moves.
  • Solvability: a goal is reachable only if the start and goal have the same inversion parity.

A* Search

Description

A* is an informed best-first search. It chooses the next node to expand using the evaluation function f(n) = g(n) + h(n), combining the cost already paid to reach a node with an estimate of the cost still to go.

Working Principle

  1. Put the start state in OPEN with f = h(start).
  2. Remove the node with the smallest f from OPEN (ties: smaller h).
  3. If it is the goal, rebuild the path through parent pointers and stop.
  4. Otherwise add it to CLOSED and generate its successors (g + 1).
  5. Ignore successors already in CLOSED or already in OPEN with a g that is as good; otherwise insert or update them in OPEN.
  6. Repeat until OPEN is empty (no solution) or the goal is selected.

Advantages

  • Optimal and complete when h is admissible.
  • Expands far fewer nodes than uninformed search.
  • Optimally efficient: no other algorithm using the same heuristic expands fewer nodes.

Limitations

  • Stores every generated node, so memory is the bottleneck.
  • Quality depends entirely on the heuristic.
  • Still exponential in the worst case.
PropertyA* Search
Time complexityO(bd) in the worst case (b = branching factor, d = solution depth); in practice governed by the heuristic's accuracy, O(bεd)
Space complexityO(bd) — all generated nodes are kept in memory
CompletenessYes, on a finite state space with positive step costs
OptimalityYes, if h(n) is admissible (never overestimates); with a closed list h should also be consistent. Both heuristics used here are admissible and consistent.

Heuristics Implemented

Misplaced Tiles

h(n) = number of tiles (blank excluded) that are not in their goal position. Cheap to compute but weak, so A* expands more nodes.

Manhattan Distance

h(n) = sum over all tiles of |row − goal row| + |col − goal col|. It dominates Misplaced Tiles (hM ≥ hT), hence expands fewer nodes while staying optimal.
